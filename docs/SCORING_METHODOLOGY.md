# Scoring Methodology

The 0–100 screening score combines:
- wastewater marker signal: 30%
- marker change: 18%
- aggregate local health-trend signal: 22%
- health-trend change: 10%
- persistence: 8%
- sampling quality: 7%
- reporting completeness: 5%

A confidence dampening factor based on sampling quality and reporting completeness reduces the apparent score when data quality is weaker. This is an operational screening heuristic, not a validated epidemiological model.
