# 🧪 WasteWatch Local

Privacy-conscious, local-first wastewater disease-signal screening dashboard.

## Features
- Explainable 0–100 screening score
- Monitor / Review / High Review / Critical Review
- Aggregate wastewater marker and local health-trend analytics
- Catchment-zone trend analysis
- Sampling-quality and reporting-completeness context
- CSV validation and local replacement
- Scored CSV export
- Interactive Plotly analytics
- No external APIs

## Responsible use
Use aggregate, authorized records only. This tool does not diagnose disease, confirm outbreaks, identify individuals, estimate individual risk, or establish causation. It is not a substitute for public-health surveillance or qualified epidemiological interpretation.
